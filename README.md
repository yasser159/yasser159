# Hi, I'm Yasser 👋

I build native macOS and iOS apps in Swift/SwiftUI, web and mobile apps in React / React Native / Expo, and a lot of my own developer tooling. Based in Victoria, BC.

## What I'm working on

- **YanBerg** — keyboard-first, Bloomberg-style workstation for US equities and options
- **MacClean** — a 16-bit-style game that scans your Mac for spyware and junk
- **SearchPro** — Firefox extension where a local model reads your search results and answers with sources
- **Shopping Scout** — MCP server that turns Claude into a local shopping agent for Victoria
